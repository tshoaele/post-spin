Using Post Spin

Choose a topic and press Spin. Edit the draft, then copy it into your social app. Nothing is posted automatically. Copying does not mark a post as published.

Mark as posted removes a draft from spins. Archive hides it until restored. Favourites only limits the pool. Reset filters changes neither favourites nor history.

Download a backup before clearing app/browser data or changing devices. Restore replaces the current collection after confirmation. Use the font loader again on a new device. Export/import does not automatically sync devices.

For fresh drafts, copy the AI instructions into a service you choose, then import the returned JSON. That external service’s terms and charges apply. This app has no live AI generation.

AI can repeat ideas or invent experiences. Read every draft. Add first-person answers only when they are true. If copy is blocked, select the text and use your device’s Copy command.

The starter bank has 50 drafts; imports can grow it. File imports are limited to 10,000 drafts per batch and 500 characters per draft. The app is not designed to guarantee sales, engagement, diagnoses or advice.
